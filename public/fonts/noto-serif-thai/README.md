# Summon button typography

Noto Serif Thai, weight 600, normal width; SIL Open Font License (see OFL.txt).
Upstream: https://github.com/google/fonts/tree/main/ofl/notoserifthai
The original variable TTF is retained at assets/ui/summon-classic/noto-serif-thai-source.ttf.
Runtime WOFF uses fontTools: instantiate wght=600, wdth=100, subset U+0020–00FF / U+0E00–0E7F plus ×, •, …; retain shaping tables. Thai vowels remain live text.
