# Summon action typography

Noto Sans Thai, weight600 and width100, from https://github.com/google/fonts/tree/main/ofl/notosansthai.
SIL Open Font License: OFL.txt. Delivery WOFF is instantiated with fontTools, preserving Thai shaping, and subset to ASCII/Latin1, Thai and the common bullet/ellipsis. This local face is used on the new gate/repeat controls; it has no runtime Google Fonts dependency.
