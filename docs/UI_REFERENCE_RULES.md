# UI Reference Rules — กฎตรวจงาน UI ให้ตรงภาพอ้างอิง

**CANONICAL · ผู้ใช้สั่งเพิ่มโดยตรง 2026-10-25**

> “เพิ่ม rule ปรับให้เหมือนกับรูปตัวอย่างเป๊ะตรวจสอบให้เหมือน พร้อมส่งรูปจริงกับรูปตัวอย่างเพื่อเทียบดู”

ใช้กับทุก agent รวม Codex และ Claude และทุกงานสร้าง/แก้ UI ของ Eldervane

1. ก่อนแก้ เปิดอ่าน `docs/design/eldervane-ui/README.md` และเปิดภาพอ้างอิงของหน้า/สถานะนั้นจริง รวมภาพเพิ่มเติมหรือ crop ล่าสุดที่ผู้ใช้เลือก ห้ามทำจากความจำหรือชื่อไฟล์อย่างเดียว
2. เป้าหมายคือ **เหมือนภาพตัวอย่างเป๊ะในส่วนการออกแบบ**: โครงหน้า ตำแหน่ง ขนาดและสัดส่วน ช่องไฟ padding กรอบ/มุมตัด ความหนาและสีเส้นทอง ความเงา แสงเงา ลวดลาย ปุ่ม ฟอนต์ ไอคอน ภาพพื้นหลัง และลำดับชั้น ห้ามเพียงใช้สีคล้ายแล้วเรียกว่าตรงแบบ หรือจัด layout ใหม่ตามความชอบของ agent
3. ข้อมูล/ภาพตัวละคร/กติกาจริงยังต้องถูกต้องตามคำสั่งผู้ใช้และ canonical gameplay docs ไม่เพิ่มของรางวัล ฮีโร่ สกิล หรือเปลี่ยน grid เพื่อเลียนตัวเลข/ความคลาดเคลื่อนใน draft รายงานความต่างด้านข้อมูลหรือกติกาแยกเป็นข้อเฉพาะจุด ไม่ใช้เป็นข้ออ้างให้โครงหน้า/กรอบ/ปุ่มส่วนอื่นต่างตามไปด้วย ถ้าเจอข้อกำหนดที่ขัดกันจริงให้ยกจุดที่ขัดกันขึ้นมาโดยตรง
4. หลังแก้ ต้องรันเกมจริงและตรวจทุกหน้า/สถานะที่แตะ ทั้ง desktop และมือถือที่เกี่ยวข้อง ตรวจสัดส่วนจาก viewport ที่ระบุ เทียบขอบเขตองค์ประกอบและดูรายละเอียดภาพขยาย แก้จุดที่ไม่ตรง/ล้น/ถูกตัดก่อนส่ง ไม่ใช้ผล typecheck/build/tests แทนการตรวจภาพ
5. **ส่งเป็นคู่ทุกครั้ง**: ภาพอ้างอิงที่ใช้ + screenshot จริงของ implementation ในหน้า/สถานะเดียวกัน พร้อมภาพวางข้างกันหรือหน้าคู่เทียบ และลิงก์แยกเปิดต้นฉบับทั้งสอง ระบุ viewport และสถานะ/ข้อมูลทดสอบ ภาพจริงต้องมาจากเกมที่รันจริง ห้าม gen/รีทัชภาพจริงให้เหมือนแบบ หรือใช้ภาพ design draft อ้างว่าเป็น implementation
6. รายงานจุดที่ยังต่างอย่างตรงไปตรงมา ถ้ายังต่างเรื่องโครง สัดส่วน กรอบ สี/เงา ปุ่ม หรือไอคอน ห้ามอ้างว่า “เป๊ะ/ตรงแบบแล้ว” หรือถือว่าหน้านั้นผ่านเอง การยืนยันความสวยงามเป็นของผู้ใช้ การให้ทำหน้าต่อไปไม่อนุญาตให้ Deploy โดยอัตโนมัติ
7. เก็บเอกสารและหลักฐานใน `docs/` ตามขอบเขตที่ผู้ใช้อนุญาต อัปเดตสถานะรีวิวของหน้าให้ตรงล่าสุด คำสั่ง No Deploy ยังคงมีผลจนกว่าผู้ใช้จะสั่ง Deploy ชัดเจน

**ลำดับเมื่อทบทวน:** องค์ประกอบ/สัดส่วน → ภาพและกรอบ → สี/วัสดุ/แสงเงา → ตัวอักษร/ไอคอน → responsive/interaction → ส่งคู่เทียบให้ผู้ใช้ตรวจ
