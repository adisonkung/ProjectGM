# Ascension mechanics V1 review

Actual game captures on desktop 1440×900 and landscape mobile 932×430. Each device has nine captures and a verification JSON with actual targets, FX, status modifiers and engine events. No page errors.

The fixture raises party HP and reduces ATK for uninterrupted visual review, selects cooldowns, disables automatic hero skills and injects Aegis Break through the real engine method. These are visual fixtures, not the balance simulation. There is no compositing of actors/effects in the original PNGs.
