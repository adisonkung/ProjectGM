# Actual guardian 4×2 review

Desktop 1440×900 and landscape mobile 932×430. Thirteen game screenshots each, captured from the running Angular battle scene. Verification JSON records actual unit cells, camera, footprints and skill state. Both runs reported zero browser errors.

Orange outlines reserve the boss's real cells; O marks its anchor. Colored hero boxes show each logical cell; dots show rendered foot positions. Shared-cell labels list all occupants. Overlays are temporary diagnostics and are not shipped UI. The fixture keeps the original heroes, raises their HP and uses manual skills so the boss cast can be inspected.
