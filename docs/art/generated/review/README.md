# ภาพจริงหลังนำอาร์ตเข้าเกม

**56 screenshots จากเกมจริง** · Desktop1440×1000 / Mobile390×844 และผลชนะ844×390 · isolated save fixture (7heroes,5sword tiers + armor/trinket,ทดลองcraft/equip) · reduced-motion. ไม่มีการรีทัช screenshot. WebP เป็นการเข้ารหัสภาพเดิม; SHA-256 ของ PNGต้นฉบับ/ขนาดอยู่ใน screenshots.json.

งานนี้เปลี่ยนอาร์ต โดยคง layout/UI ที่ตรวจไว้ก่อนหน้า แบบอ้างอิงเป็นบอร์ดอาร์ตที่ผู้ใช้เลือก มิใช่ข้ออ้างว่า layout ทั้งหน้าตรงกัน ภาพต้นฉบับและภาพจริงเปิดแยกได้ทุกหัวข้อ ยังรอการตรวจจากผู้ใช้ ไม่ Deploy.
