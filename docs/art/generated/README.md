## รอบเชื่อมภาพตกหล่น

- `DungeonRewardIconComponent` ใช้ภาพตามitem IDจริงแล้ว ครอบคลุมยา ตำรา เศษอุปกรณ์ แร่ และUniversal Memory; ภาพBTที่ยังไม่ผลิตใช้fallbackกลางต่อไป ไม่ใส่หน้าไป๋หลงให้หินทุกตัว
- รางวัลพื้นฐาน/รายละเอียด/โบนัสสุ่ม/ผ่านครั้งแรกใช้ภาพตามIDเดียวกัน; EXPแยกภาพจากไอคอนฮีโร่
- หน้าอุปกรณ์มี **คลังวัสดุ** อ่านจำนวนจากเซฟจริงครบ15ประเภท รวมเศษตำราI–IIIที่ก่อนหน้านี้ไม่มีหน้าดูจำนวน แสดง0เมื่อไม่มี กดพับเก็บได้ ไม่เพิ่มไอเทมหรือแก้เซฟ
- ต้นทุนตีบวกแสดงภาพแร่และทอง; ปุ่มยกเลิกโฟกัสใช้ภาพปิด; ภาพพักรบใหญ่ใช้ภาพpauseที่Gen
- ฉากForgeเก่าถูกระบุsupersededอย่างถูกต้อง แค็ตตาล็อกแยกภาพเก่า/ตัวอย่าง/แนวทางชัดเจน
- ราคา โอกาสดรอป สถานะไอเทม กติกาสวมใส่ สูตรและผลรางวัลคงจากระบบจริง

## ภาพที่เก็บให้ดู แต่ไม่ใช้แทนไอเทมจริง

- ตัวอย่างหิน/เศษหินไป๋หลงI–III6ภาพ: พักรอเปลี่ยนPortraitตามคำขอ เปิดดูในคลังGMได้
- Universal breakthrough concept1ภาพ: ยังไม่มีitem ID/ระบบแปลงรองรับ จึงอยู่หมวดแนวทาง
- Boardอุปกรณ์/Forge3ภาพ: ภาพออกแบบทั้งแผ่น ใช้เป็นref ไม่ใช้เป็นไอเทม
- ฐานอุปกรณ์เก่า6/ออร่ารูปนิ่ง5/ฉากForgeเก่า1: เก็บเทียบ แต่ถูกแทนในหน้าที่ใช้งานแล้ว
- เวอร์ชันที่ผู้ใช้ปฏิเสธ เช่นสีอาชีพเก่า ดาบ/คทาอ้วน ไม่ย้อนกลับมาใช้

## งานที่ยังไม่ได้ทำ

- ผลิตหินเฉพาะรายฮีโร่หลังเปลี่ยนPortrait และระบบแปลงเป็นหินรวม1:1เมื่อเลื่อนขั้นครบ
- แยกช่องสร้อย/แหวน/Relic และmigrationกติกา/เซฟ; ปัจจุบันสร้อยกับแหวนเป็นรูปลักษณ์ในช่องACCESSORYเดิม
- รวมชนิดอาวุธเป็นดาบในระดับgameplay; ปัจจุบันภาพเป็นดาบ แต่ฐาน/family restrictions/ค่าพลังเดิมคงอยู่
- ภาพฮีโร่หรือspriteที่เปลี่ยนชุด/อาวุธตามอุปกรณ์ ยังไม่ได้ผลิต
- ไอคอนที่ยังไม่เคยGen เช่นimport/load, fullscreen, palette, people, generic star/book/crystal และstatus/affixบางชนิด ยังใช้glyph ไม่ถือว่าเป็นภาพGenที่ตกหล่น
- ตรวจความสวยงามจากผู้ใช้ก่อนmerge/Deploy; รูปที่มีrendererแล้วบางภาพขึ้นกับstat/ไอเทม/สถานะปุ่ม ไม่ได้โหลดพร้อมกันทุกหน้า
