2026-10-25 · รอบก่อนถูกผู้ใช้ปฏิเสธว่าไม่ตรงแบบ · รอบนี้ยังไม่ Deploy

ผู้ใช้เพิ่มกฎโดยตรงให้ปรับเหมือนตัวอย่างและส่งภาพจริงคู่กับแบบ บันทึกเป็น canonical `UI_REFERENCE_RULES.md`, PROJECT_RULES §21 และชี้ให้อ่านจาก AGENTS/CLAUDE/design README

## สิ่งที่แก้จากรอบที่ถูกปฏิเสธ

- เตรียมรบ: แผ่นกลับหอคอยทรง chapter, สนามกรอบทองหลายชั้น, หัวเขตมีกรอบกลาง, footer สามส่วนตรงกับ11A — ทีมปัจจุบันห้าการ์ด/แท็บ A B C, สำรอง, จัดอัตโนมัติ/เริ่มสู้ ไม่แยกเป็นหลายแถบเหมือนรอบก่อน
- เตรียมรบใช้ opt-in `battleLayout` ของ Placement; standalone Formation และ lab ใช้รูปแบบเดิม ข้อมูลและตำแหน่งจริงยังใช้ TeamService/CDK handlers เดิม
- แท็บทีมมีเมนู native details สำหรับบันทึก/แก้ชื่อ เพื่อคงคำสั่งจริงโดยไม่เอาสองปุ่มใหญ่มาเบียดชื่อแท็บ การกดเลือกการ์ดฮีโร่แล้วแตะสนาม/สำรองยังใช้ handler เดิม
- ต่อสู้: ห้าการ์ดแบบรูป/ชื่อ/HP/มานา/สามสกิล มีแถบคำสั่งเดิมใต้สกิล พร้อม AUTO/พลังพิเศษในกรอบแยกใต้สนาม ตาม11B ปรับแค่แถบ foot ไม่เปลี่ยนห้าแถวของสนามหรือจังหวะเอนจิน
- พักรบ/ชนะ/แพ้: ตราสัญลักษณ์โลหะจาก asset atlas ใหม่อ้างอิง13, พื้นหลังปราสาท, ข้อความและปุ่มหลักสองปุ่ม, กรอบรางวัล และปิดหน้าต่าง มียอด EXP รวมฮีโร่จริง และแถบขยายแยกรายตัว/คำสั่งเพิ่มเติม แทน popup ยาวแน่นจากรอบก่อน

## หลักฐานการเทียบ

[เปิดภาพคู่เทียบและภาพจริง/ต้นฉบับแยกหัวข้อ](https://github.com/adisonkung/ProjectGM/blob/789173a5255a1038afeefa566e8034b9f59320ff/docs/review-images/2026-10-25-battle-match/README.md) — 19ภาพ lossless, index/validation และกฎที่ผู้ใช้สั่งเพิ่ม ไม่มี source patch หรือ Deploy

ภาพอ้างอิงต้นฉบับ11/13ไม่แก้ไฟล์ ภาพคู่ใช้ browser แสดง crop จากต้นฉบับข้าง screenshot จริง ภาพ dialog ขวาเป็น locator screenshot ของแผงที่รันจริง ปรับความกว้างการแสดงผลให้เท่ากันเพื่อเทียบ ไม่มีการรีทัชภาพเกม ภาพจริงเต็มจอและมือถือเปิดแยกได้ พร้อม viewport และ crop coordinates ใน comparison-report/validation

**ความต่างที่คงตามเกมจริงและคำสั่งเดิม:**

- สนามรวม5×16 แบ่ง scenery2/เล่นได้3; จำนวนแถว/สัดส่วนสนามที่ draft วาดเกินไม่ถูกนำมาเปลี่ยนกติกา
- ใช้ฮีโร่ ภาพ คลาส ตำแหน่ง และสกิลจริง ไม่เปลี่ยนเป็นชื่อ/ตัวละครที่ดราฟวาดขึ้น; combat snapshots เป็นจังหวะจริงที่ตำแหน่ง/คูลดาวน์เปลี่ยนได้
- ชนะชั้น1ให้ Universal Memory10 +EXPรวมฮีโร่250 (50×5) ไม่เพิ่มทอง600/เพชร150ตามดราฟ
- หัวเมนูใช้เวอร์ชันโลโก้/เมนูที่ผู้ใช้ตรวจไว้ก่อนหน้า
- ไอคอน material ยังเป็น generic glyph จากชนิด item จริง ตาม backlog ที่ผู้ใช้รอทำทีเดียว; ตราโลหะ UI เป็น asset ผลิตใหม่ตามภาพ13 ไม่ใช่ไฟล์เลเยอร์ของดราฟต้นฉบับ

ไม่ใช้ตัวเลขเปอร์เซ็นต์/ผลเทสต์อ้างว่า pixel-perfect ภาพวางคู่มีไว้ตรวจความเหมือนจริง และยังรอผู้ใช้ตรวจ งานเกม/กติกาไม่เปลี่ยน
