# Eldervane — ชุดล่าสุดตั้งแต่ปกหลัง/สันหนังสือ

รวม 22 ภาพ ตามช่วงงานที่ขอ:
- book: ปกหลัง สัน และขอบกระดาษ
- vfx: แสงจันทร์ วงเวทสองวง ระเบิดฟ้า/ทอง เปลี่ยนฟ้าเป็นทอง ลำแสงหมุนฟ้า/ทอง และแสงช่องฟ้าทอง
- scene-a: ภาพห้องขยาย 2 เท่า และร่างชั้นฉาก 8 ไฟล์
- scene-c: ภาพมุมต่ำล่าสุด

ใช้เฉพาะเวอร์ชันล่าสุด ไม่มีแบบทดลองแท่นและชุดลายผิวห้อง 3D รุ่นเก่า
ภาพปกหน้า ฟ้าดาว เปลวเทียน และ oculus flare สีฟ้าที่ส่งก่อนช่วงปกหลังไม่ได้รวมซ้ำใน ZIP นี้

สถานะ: เลเยอร์ฉาก A ยังต้องจัดขนาดและตำแหน่งให้ตรงภาพต้นทาง 3344 × 1882 ก่อนซ้อนใช้งานจริง; c_full ยังรออนุมัติก่อนแยกชั้น C; VFX ยังต้องเตรียมขนาด/กริดและตรวจใน runtime
ขนาดจริงและ SHA-256 ของทุกภาพอยู่ใน manifest.json ชุดนี้รวมไบต์ต้นฉบับโดยไม่ปรับหรือแก้ภาพ
